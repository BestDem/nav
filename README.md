# Игра — Unity WebGL

Версия редактора: **Unity 6000.4.9f1**. Для WebGL требуется модуль WebGL Build Support.
Открывайте проект из корня репозитория через Unity Hub.

## Получение проекта

Модели, текстуры и другие крупные ресурсы хранятся в **Git LFS** без потери качества.
Установите Git LFS: https://git-lfs.com/ . Затем выполните:

```sh
git lfs install
git clone https://github.com/BestDem/nav.git
cd nav
git lfs pull
```

Если проект уже клонирован, выполните `git lfs install` и `git lfs pull` в его каталоге.
Дождитесь загрузки LFS-файлов перед открытием Unity. Ничего вручную распаковывать не нужно.
Не используйте GitHub Download ZIP для рабочего клона: используйте Git с LFS.

Добавляйте ресурсы вместе с соответствующими `.meta`: в них находятся идентификаторы,
на которые ссылаются сцены и материалы. Перемещайте ресурсы через Unity.
Git LFS не уменьшает сами файлы и требует их загрузки; он хранит бинарные ресурсы
отдельно от обычной истории Git. Хранилище и трафик LFS учитываются по квоте GitHub.

## Авторизация

Игра получает токен авторизованного пользователя от сайта. Тестовый токен в репозитории
отсутствует, автоматическая загрузка локального тестового токена отключена.
Интеграция: `Assets/Scripts/VSM_Unity_WebGL_Dialogue/README.txt`.

## Проверки и сборка

- `node Tests/voice-bridge.test.cjs`
- `python3 Tests/ScenarioFlow/run.py` (использует локальный C# runtime Unity на macOS).
- WebGL-сборку можно выполнить через Unity или метод `ServerWebGLBuild.Build`.

`Library`, `Temp`, `Build`, `Builds`, `Delivery` и `UserSettings` не отправляются в Git.
Готовые сборки передаются отдельно от исходного проекта.
